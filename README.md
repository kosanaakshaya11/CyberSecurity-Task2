# Phishing Email Detection & Awareness Report

## Tools Used

* Public Phishing Email Samples
* Canva
* Email Analysis Techniques

## Analysis Approach

1. Collected phishing email samples
2. Identified phishing indicators
3. Classified risk levels
4. Created awareness guidelines

## Findings

* All samples contained phishing characteristics.
* Common indicators included suspicious links, urgency, and generic greetings.
* User awareness is critical for phishing prevention.

## Conclusion

Phishing attacks rely on social engineering. Proper training and verification can significantly reduce the risk of successful phishing attacks.
